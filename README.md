# Zoho CRM - Lead to Order Automation Project

## Project Overview

This is a real-life Zoho CRM implementation for a B2B service company to manage leads, automate follow-ups, assign sales reps, and track deals until invoicing. It demonstrates workflow automation, Deluge scripting, and CRM best practices.

## Business Scenario

**Company:** B2B service provider

**Challenges:**

* Leads not followed up on time
* Uneven lead distribution
* Manual updates
* Limited visibility on sales performance

**Solution:** Implement Zoho CRM automation using:

* Leads, Contacts, Accounts, Deals modules
* Custom fields and layouts
* Workflows and assignment rules
* Deluge functions for automation
* Reports and dashboards

## Key Features

* Round-robin lead assignment
* Automated follow-up tasks
* Rating update based on lead source
* Reports and dashboards for sales monitoring
* Role-based profiles and permissions

2. Check Deluge scripts in `Deluge_Scripts/` for function examples.
3. Replace placeholder screenshots in `Screenshots/` with actual CRM screenshots.
4. Import sample data in `Sample_Data/` to replicate the project.
